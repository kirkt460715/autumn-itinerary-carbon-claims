# 短途研学路线的低碳比较与标签核准

研学行程交通估算、供应商行驶记录和行程卡比较声明。 `data/` 中的记录均为虚构业务数据。

使用 Python 3.11.2。资料核验与排放核算仅依赖标准库。

## 工作流目标

把“**核算 → 基准同口径比较 → 标签核准 → 行程卡/专题汇总 → 变更回查**”接成
一个可重复、可回查的工作流，避免报名页标签因两类错误而失去意义：

- 只看两馆间直线距离，忽略合乘、空驶与接回同一批乘客的完整服务；
- 拿坐满车的人均量去和需要轮椅位的小团比较。

## 目录结构

```

  accounting.py  车段排放、合乘容量份额、空驶追溯分摊、每儿童份额、守恒校验
  benchmark.py   基准排放、同等服务口径门槛、共享车次一致取值
  review.py      标签判定、变更通知、卡片复核、专题合计
  workflow.py    按 as-of 时点编排整轮；取消后剩余团重算
  report.py      导出 CSV 与 Markdown 复核报告
  cli.py         命令行入口

```

## 核算与认领规则（共同、公开、可解释）

1. **车段运营排放** = 服务车公里 × 适用因子（克 CO2e/车公里），里程与因子
   各有上下界，排放区间下界取 `km_lo × rate_low`、上界取 `km_hi × rate_high`。
2. **合乘份额按占用容量单位划分**：每团容量单位 = 儿童 + 陪同成人 + 轮椅位。
   轮椅位是必须保留的专用容量，计入分母，因此轮椅小团不会被“坐满车人均量”误伤。
3. **空驶段**（`linked_leg`）不产生新归属，按关联载客段的同一份额认领，
   即“接回同一批乘客所需的空驶”跟着该批乘客走。
4. **守恒校验**：每段各团认领之和必须等于该车段运营排放，份额之和为 1，
   保证同一服务车次在分拆团次后既不消失也不翻倍。
5. **比较单位**固定为“一名儿童及其必需交通份额”，每儿童 = 本团认领总量 / 本团儿童数。

## 不确定来源（逐段登记，互不混淆）

| flag | 含义 | 对标签的影响 |
| --- | --- | --- |
| `mode_unconfirmed` | 交通方式尚无法确认 | 阻断，不能静默替换因子 |
| `factor_missing` | 正式因子表无适用发档 | 阻断 |
| `distance_pending` | 里程待核对（上界缺失） | 阻断 |
| `boarding_estimated` | 载客为订购时假设而非实跑确认 | 不阻断，但须随范围标明假设 |
| `plan_basis` | 车段是计划版本而非实跑 | 不阻断，但须标明假设 |

阻断项未消除前不得使用标签，只能展示明确标明假设的排放范围。

## 基准与标签口径

- 基准必须通过**同等服务门槛**：同一研学服务资格（event_key）、地区一致、
  出入场时窗覆盖本团签到/最迟接回、轮椅可达性匹配、容量不低于最低成团人数、
  比较时点前已登记、因子可得。未通过即记录原因，不能成为减排证据。
- **共享车次**（`benchmarks.shared_legs`）在双方计算中复用同一车段台账与同一
  钉版因子，机制上禁止各取对自己有利的未知值。
- 保守减排 = 基准下界 − 本路线上界（每儿童克）。只有保守差距仍达到标签
  `minimum_saving`，且无阻断项与已生效取消/换车通知，才允许在适用团型与
  售卖窗口使用标签。
- 可比较但未采用的其他基准，会在标签决策中留下确切条件与不采用原因。
- **已兑现行程保留原声明**，另附当前因子/实际载客下的结算复核说明。

## 变更通知与卡片

- 通知按 `received_at` 与 as-of 比较：未送达的登记为 `pending_future_receipt`，
  不改变本轮在售口径；已送达的取消/换车/绕行按动作生效。
- 团次取消后，剩余团队按实际服务**重算份额**，旧人均数作废
  （见 `workflow.rerun_after_cancellation`）。
- 支线卡与总卡引用**同一 tour（同一批孩子）**的交通时不产生独立贡献，专题
  合计不得重复；支线另售给**不同 tour**（即便共享车次）则独立贡献成立，
  各团按份额分别认领，车次总量仍守恒。
- 专题总数可反查每张卡的覆盖范围（tour+车段）与所用基准。

## 运行

在仓库根目录：

```bash
# 测试（源表格式 + 全部业务规则）
python3 -I -m unittest discover -s tests -v

# 按复核时点产出一轮结果（CSV + Markdown）
python3 -I run_workflow.py --data data --as-of 2026-11-23 --out out/2026-11-23
python3 -I run_workflow.py --data data --as-of 2026-11-25 --out out/2026-11-25
```

每个 as-of 目录产出：车段台账、每团认领、offer 每儿童区间、基准比较、
标签决策、卡片复核、专题合计、通知登记，以及人工可读的 `review_report.md`。
不同 as-of 快照保留了因子更订、通知送达前后的可回查差异。

各表来源及字段约定见 [资料约定](data-contract.md)。
